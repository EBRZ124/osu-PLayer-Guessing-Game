# osu-PLayer-Guessing-Game
A small python pet project using tkinter. A quiz game surrounding various osu! content creators and players

The main file is PlayerGuessing.py where the layout and everything visual you see happens

answerlogic.py is a seperate file for the algorith to select a random player with three answers and one of them being the correct one (also randomised). It's most certainly not optimal, and I believe it's not fully random at the moment (30.09)

Images folder just has images of the players in the quiz
